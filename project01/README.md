# Project01 — RoboMaster 2027 MuJoCo 仿真平台

基于 MuJoCo 搭建的 RoboMaster 2027 飞镖仿真平台，支持飞镖六自由度运动、镖靶运动控制、实时状态监测，以及通过 TCP/UDP 与外部 Python 工程交换传感数据和控制量。

## 1. 文件说明

| 文件 | 主要职责 | 具体功能 |
|---|---|---|
| `main.py` | 程序入口 | 加载 MuJoCo 模型并启动仿真与控制面板 |
| `lib.py` | 仿真控制 | 飞镖发射、镖靶运动、仿真循环、实时状态监测 |
| `dart_interfaces.py` | 物理接口 | 获取传感数据，合成主动、被动力和力矩，并施加到飞镖 |
| `bridge_ipc.py` | 通信接口 | 建立 TCP/UDP 本机通信，与外部 Python 工程交换数据 |
| `model.xml` | 物理模型 | 定义场地、飞镖、镖靶、质量、惯量及碰撞参数 |
| `meshes/` | 三维模型 | 存放场地、飞镖及镖靶的网格文件 |

## 2. 三个通信接口

| 接口 | 方向 | 数据 | 频率 |
|---|---|---|---|
| 传感接口 | 输出 | 飞镖视角 RGB 图像、三轴线加速度、三轴角速度 | 30 Hz |
| 主动接口 | 输入 | 三轴主动修正力、三轴主动修正力矩 | 30 Hz |
| 被动接口 | 输入 | 三轴被动力、三轴被动力矩 | 30 Hz |


## 3. 运行方式

```bash
python main.py
```

**注意：** 通信目标频率为 30 Hz，实际图像帧率受计算机渲染性能影响。
