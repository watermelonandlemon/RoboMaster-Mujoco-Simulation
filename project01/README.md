# RoboMaster 2027 MuJoCo

## 1. 文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 主程序，启动仿真 |
| `lib.py` | 实现发射控制、镖靶运动、仿真循环及控制面板 |
| `dart_interfaces.py` | 定义传感接口及主动、被动六维力/力矩输入 |
| `bridge_ipc.py` | UDP通信、输入监听、四话题发布及多订阅者管理 |
| `vision_gt.py` | 绿灯中心投影与中心射线遮挡查询，不读取RGB |
| `check_vision_gt.py` | 本机真值自检，可选 `--render` 检查渲染对象ID |
| `model.xml` | 定义仿真场景及模型参数 |
| `meshes/` | 存放场地、飞镖和镖靶的三维模型 |

## 2. 接口定义

| 接口 | 通信方式 | 数据内容 |
|---|---|---|
| 主动输入 | UDP 18981 | 六维主动修正力/力矩 |
| 被动输入 | UDP 18982 | 六维被动力/力矩 |
| 数值输出 `dart/state` | UDP 18980 | 飞镖位置、速度、姿态及六维作用力等 |
| IMU输出 `dart/imu` | UDP 18980 | 机体系线加速度、角速度 |
| 图像输出 `dart/image` | UDP 18980 | 飞镖第一视角 RGB 图像 |
| 视觉真值 `dart/vision_gt` | UDP 18980 | 对面基地绿灯中心像素与可见性 |

**输入格式：**

`[Fx, Fy, Fz, Mx, My, Mz]`

力的单位为 N，力矩的单位为 N·m。主动与被动输入分别监听，合成后施加于飞镖，被动输入不包含重力。

**输入机制：**

采用独立监听，100Hz检查数据。收到新数据后持续保持，支持多个发布者同时发送。

**输出机制：**

采用 UDP 发布/订阅机制，支持多个程序同时订阅，可选择 Topic 及数值字段。图像采用 zlib 压缩和 UDP 分片传输。各输出目标频率为 30Hz，实际频率取决于仿真及渲染性能。
新增话题使用与同帧图像一致的 `frame_id/time_s`。只订阅数字不渲染图像。接收端运行 `project02/vision.py`；`video.py --show-gt` 可显示同帧中心十字。详细字段与数据来源见上级目录 `使用说明_视觉真值.md`。
