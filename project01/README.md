# RoboMaster 2027 MuJoCo

## 1. 文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 主程序 |
| `lib.py` | 实现发射控制、镖靶运动、仿真循环及实时状态监测 |
| `dart_interfaces.py` | 定义传感接口、主动及被动六维输入，完成力和力矩的合成与施加 |
| `bridge_ipc.py` | UDP通信、输入监听、数据保持及传感器多订阅者分发 |
| `model.xml` | 定义仿真与模型参数 |
| `meshes/` | 场地、飞镖和镖靶的三维网格模型 |

## 2. 接口定义

| 接口 | 通信方式 | 数据内容 | 频率 |
|---|---|---|---|
| 主动输入 | UDP 18981 | 三轴主动修正力、三轴主动修正力矩 | 100Hz 监听 |
| 被动输入 | UDP 18982 | 三轴被动力、三轴被动力矩 | 100Hz 监听 |
| 数值输出 `dart/state` | UDP 18980 | 仿真时间、三轴加速度、三轴角速度、六维作用力等 | 目标 30Hz |
| 图像输出 `dart/image` | UDP 18980 | 飞镖第一视角 RGB 图像 | 目标 30Hz |

**输入格式：**

`[Fx, Fy, Fz, Mx, My, Mz]`

其中力的单位为 N，力矩的单位为 N·m，均采用飞镖机体系。主动与被动输入逐分量相加后施加于飞镖，被动输入不包含重力。

**输入机制：**

两路输入独立监听，每约 10ms 非阻塞读取一次。初始值为零，收到新数据后更新并持续保持，不设置超时自动清零。支持多个发布者向同一通道发送，最后接收到的有效六维数据覆盖原值；发送频率由各发布程序独立控制。

**输出机制：**

采用类似 ROS Topic 的 UDP 发布/订阅方式，支持多个程序同时订阅，并可选择仅接收数值、仅接收图像或两者同时接收。数值话题支持按字段筛选；图像采用 zlib 压缩和 UDP 分片传输。实际输出帧率(约12.8帧)受仿真及渲染性能影响。
