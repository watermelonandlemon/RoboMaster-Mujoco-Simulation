# 无控飞镖 MuJoCo 模型

## xianjiaoda_wukong.xml
是MuJoCo MJCF模型文件,在"mujoco-3.17.0-windows-x86_64\bin\mujoco_studio.exe"中导入即可;
来源于2026西交RoboMaster社区公开资料中的飞镖(非制导镖);
不可人为设定运动指令，运行后即自由落体;

## 模型设置
1. 整支飞镖被定义为一个 body，并使用 freejoint，是单刚体自由运动模型，没有舵面关节、气动力、推力或控制器。
2. STL 原始单位为 mm，MJCF 中通过 scale=0.001 转换为 m。
4. 飞镖头部朝 +Z，尾翼朝 -Z；模型初始放置在 z=0.30 m。
5. 详细 STL 只用于显示,碰撞使用简化的胶囊体和尾翼包络盒，以提高仿真稳定性。
6. 当前 XML 中质量暂按 0.3915 kg 设置，这是规则中的飞镖最大重量上限，不代表该模型的实测质量。
7. 转动惯量 0.0010 / 0.0010 / 0.00003 kg·m² 是初始占位估值，不是 SolidWorks 质量属性导出值。
